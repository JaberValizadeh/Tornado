# Tornado Consulting Group (TCG) Website

A modern, responsive website for Tornado Consulting Group built with Next.js and Tailwind CSS.

## Features

- **Modern Design**: Clean, futuristic UI with animations and professional typography
- **Mobile-First**: Responsive design that works perfectly on all devices
- **SEO Optimized**: Proper meta tags, structured data, and accessibility features
- **Performance**: Fast loading with optimized images and code splitting
- **Animations**: Smooth animations using Framer Motion

## Tech Stack

- **Framework**: Next.js 14 with App Router
- **Styling**: Tailwind CSS with custom design system
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **TypeScript**: Full type safety

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Pages

- **Home**: Hero section, services overview, testimonials, and CTAs
- **Services**: Detailed AI consulting offerings with process steps
- **About**: Mission, vision, values, and founder profile
- **Case Studies**: Success stories with measurable results
- **Contact**: Contact form and Sydney location details

## Components

- **Header**: Sticky navigation with mobile menu
- **Footer**: Links, contact info, and compliance placeholders
- **Button**: Reusable button component with variants
- **Card**: Consistent card styling across the site

## Design System

### Colors
- **Primary**: Deep blue/navy (#1e40af to #172554)
- **Accent**: Electric green/cyan (#10b981 to #022c22)
- **Background**: Clean white and light gray

### Typography
- **Font**: Inter (Google Fonts)
- **Hierarchy**: Proper heading structure for SEO
